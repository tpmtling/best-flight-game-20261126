Sky Courier: Alpine Run — a complete flight game that runs offline in a desktop browser from its own static files. Fly a bush courier down a mountain valley in chase view: thread the glowing rings, mind the fuel, climb over the ridges, and put her down on the runway strip. Three legs (Valley Run, Ridge Crossing, Dusk Landing), each with its own rings, wind and light; throttle, pitch and bank discipline, fuel and damage, landings that read as landings. Keyboard and mouse, WebAudio engine and wind, lit instruments on the panel — altitude, speed, heading, attitude, fuel and throttle — and a HUD that always shows the next ring.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network.
